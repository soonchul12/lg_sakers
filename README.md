# LG Sakers attendance study

권순철의 LG 세이커스 관중 분석·마케팅 제안 프로젝트.

**사이트:** https://soonchul12.github.io/lg_sakers/

## 화면과 기능

- 시즌과 주중/주말 필터, 경기 차트 페이지 탐색, 키보드로 선택하는 경기별 상세 정보
- 시즌별 평균·요일별 비교·월별·라운드별 차트
- 리그 벤치마크와 LG 원자료의 집계 수치 차이 표시
- 네 가지 마케팅 제안의 실행 제약과 검증 지표
- 전북 현대·KB 스타즈·SSG 랜더스 기간 비교, 총 관중/경기당/요일별 분석
- 스크롤 진행 표시, 구간 탐색, 가벼운 등장 애니메이션, 동작 줄이기 설정 지원

HTML, CSS, JavaScript, SVG로 구현했습니다. 런타임 프레임워크나 차트 라이브러리 없이 기존 JSON 자료를 직접 표시합니다. 폰트는 Barlow Condensed와 Noto Sans KR을 사용하고 시스템 폰트로 대체할 수 있습니다.

## 실행

루트의 `index.html`을 HTTP 서버로 제공합니다. 설치 없이 Python으로도 실행할 수 있습니다.

```sh
python3 -m http.server 4341
```

기존 Vite 개발 환경을 사용하려면 `npm install`, `npm run dev`를 실행합니다. `npm run build`는 의존성 설치 없이 배포에 필요한 정적 파일과 JSON을 `dist/`에 복사합니다. GitHub Pages는 저장소 루트의 정적 파일을 게시합니다.

## 데이터와 해석

2024–25 홈경기 27건의 관중 평균은 약 3,422명입니다. 주말 11경기는 약 4,193명, 주중 16경기는 약 2,892명입니다. 월별 관중은 같은 경기별 원자료로 계산합니다. 라운드 자료와 구단 비교 자료는 기존 JSON 및 기존 프로젝트의 참고 수치를 보존했습니다.

직접 분석한 LG 평균 3,422명과 벤치마크 파일의 LG 평균 3,647명은 다릅니다. 집계 범위를 확인하기 전에는 같은 기준의 순위나 성과로 단정하지 않습니다. 마케팅 안은 제안이며 실제 시행 성과를 의미하지 않습니다. 상위 관중 경기 날짜도 이벤트 효과의 증거가 아닙니다.
